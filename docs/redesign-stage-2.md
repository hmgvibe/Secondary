# 第二階段：首頁時鐘與背景

## 已實作

- HomeClock 為 WPF 原生向量繪製：數字／翻頁／指針時鐘，使用本機時間；12／24 小時、秒數、日期、整組大小、位置與 Auto／RGB 色碼。
- 翻頁只在顯示數字變動時播放 360ms 動畫，完成移除動畫時鐘。隱藏秒數時每分鐘更新；顯示秒數時每秒更新，恢復可見時立即校時。
- Settings 的單直欄新增首頁編輯器；套用才儲存並返回首頁，無效顏色與不存在檔案不套用。恢復預設只修改編輯欄位，不刪除媒體。
- 本機 JPEG／PNG／BMP 圖片，OnLoad 解碼後關閉檔案，最大 80 MB、解碼尺寸不超過 2560×1440；不將完整原圖長期常駐。
- MediaElement 循環靜音 MP4；本機 H.264 播放與循環已用 MDN CC0 flower.mp4 驗證。使用系統已有解碼器；不安裝第三方編解碼器。格式錯誤、媒體失敗、檔案遺失會顯示提示並回退靜態背景。
- 緩慢漸層與柔和流光兩種內建背景，使用 WPF 合成動畫，24 FPS 上限；預設仍為靜態背景。
- 離頁、設定頁、隱藏、最小化、遊戲模式、session lock／disconnect、電源 suspend：停止時鐘、清除圖片、Stop／Close 影片、移除背景動畫；恢復時重建。高對比回退主題，減少動畫停用影片／翻頁效果，內建背景保持靜態。
- v3 新增可選 Home 設定；原 v3 無欄位仍使用預設值，不改副屏、熱鍵、主題與遊戲偏好，保留 v1／v2 備份遷移行為。

## 驗證與限制

Release 建置零警告／零錯誤；97 項核心測試、4981 項一般 UI 斷言通過。包含 MP4 的原生視窗測試共 5024 項斷言通過。

- 核心測試覆蓋設定往返、舊版相容、輸入淨化、路徑限制、12／24 小時午夜與中午。
- UI 回歸涵蓋 80 組 viewport／DPI／theme，另驗證三種時鐘、跨日、編輯器儲存、圖片解碼後檔案解鎖、離頁清理、減少動畫及損壞影片回退。
- `Secondary.UiTests.exe --live --video=artifacts/redesign/stage-2/flower-test.mp4` 以獨立測試視窗確認真實時計更新、可播放 MP4 時間前進／循環／釋放後無檔案鎖，以及切頁、最小化、遊戲切換。鎖定／電源事件以通知模擬，不改動使用者 Windows 狀態。
- 時鐘版面截圖在 artifacts/redesign/stage-2，標示 FIXTURE 的圖使用固定測試時間；不代表實體副屏驗收。MP4 只為測試素材，不隨應用程式發行，來源：https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.mp4。
- 尚未執行實體副屏／不同 GPU 解碼器、長時間耗用與實際鎖定／睡眠驗收；相關完整驗證屬第六階段，不宣稱固定記憶體上限。
- 快捷導航及遊戲數據仍是示意，本階段不啟動真實監測，也不執行捷徑。等待使用者確認後才開始第三階段。

## 2026-09-16 實際視窗檢查後優化

使用電腦操作技能檢查實際首頁、時鐘選單、翻頁＋流光背景與設定流程。發現套用按鈕容易捲出可視範圍、滑桿缺乏數值、內建背景仍有空白檔案欄位。

- 套用與狀態訊息移至設定頁固定底部操作列，捲動區預留 88 DIP，不遮住內容或底部導航；保留 800 DIP 單直欄。
- 大小／水平／垂直滑桿顯示百分比，加入位置歸中，大小步進為 10%。
- 僅圖片／影片顯示檔案選擇，其他背景改成對應提示。
- Release 零警告／零錯誤，97 核心測試、5348 UI 斷言通過；新增固定按鈕邊界、捲動區不重疊、條件欄位、數值與歸中測試。
- 已重新用實際視窗確認改版設定頁並按固定按鈕套用；試用後還原原本指針鐘／靜態背景，未修改顯示器與系統設定。仍不代表實體副屏或長期效能驗收。

## 首頁自訂改為獨立彈窗（取代上述固定設定頁操作列）

依使用者最新要求，首頁所有選項從全域設定頁移除，只由原有「自訂首頁」按鈕打開置中模態彈窗。彈窗可捲動，套用與關閉操作固定在彈窗內；最大 720×820 DIP，窄視窗保留四周 16 DIP 空白。打開時暫停首頁活動並限制背景操作，關閉恢復焦點與活動；Esc 不會再影響主視窗全螢幕狀態。套用才儲存，關閉後再次打開載入已儲存設定，捨棄先前草稿。

全域設定頁恢復原本單直欄，只保留顯示器、主題、快捷鍵與遊戲動畫，不再有首頁套用列。新增彈窗邊界、內容與底部不重疊、關閉放棄草稿、模式切換及 Esc／資源生命週期測試；渲染預覽在 artifacts/redesign/home-dialog。

## 導航欄大小與位置

全域設定新增導航欄選項：標準（現有響應式尺寸）／小（整個膠囊縮為標準的 80%，含圖示與間距），上／下／左／右。左右直向排列，內容區在指定方向預留空間；圓角取短邊的一半。自訂提示改為無方向箭頭的圓角氣泡，在導航欄內側顯示。v3 設定新增可選 NavigationSize／NavigationPosition，缺失或無效值回到 Standard／Bottom。

106 核心測試、5428 UI 斷言通過；新增八種組合的設定往返，以及日常／遊戲、寬／窄視窗下的 80% 比例、位置邊界、膠囊圓角、內容不重疊與提示方向。渲染預覽在 artifacts/redesign/navigation-options。

## 首頁組件化：時鐘

首頁改為 Canvas 畫布，第一個組件是時鐘。共用 HomeWidget 容器負責拖曳、等比例縮放、邊界限制、焦點與操作完成事件；時鐘只負責顯示，後續組件沿用容器。

直接拖動時鐘移位，右下角縮放，僅滑鼠懸浮或拖曳時顯示外框與把手；拖曳後保留的鍵盤焦點不會讓外框常駐。方向鍵微調、Shift 加速、Ctrl 加方向鍵縮放，Esc 取消進行中的拖曳。位置以可用畫布的相對比例保存，大小支援 30%–300%，實際顯示仍受畫布邊界限制。沿用既有 Home.X／Y／Size，保留原設定相容性；放開後才保存，保存失敗回復原位置並顯示原因。

Debug／Release 建置通過，Release 零警告／零錯誤；108 核心測試、5443 UI 斷言通過。新增三種視窗尺寸下的位置夾限、縮放比例、畫布邊界與重新載入設定驗證。使用電腦操作技能實際拖動時鐘與右下角把手，確認位置改變及時間／日期同步等比例縮放；不代表實體副屏或長期效能驗收。

## 第一批實用組件

新增日曆、便箋、倒數計時、碼錶，由首頁「＋ 組件」選擇，最多 12 個（不含原時鐘），可重複新增。互動內容不覆蓋拖曳層，改由標題列拖動；右鍵標題移除時先確認。移除會解除 Canvas 事件及停止計時器；離頁、最小化、遊戲模式停用畫面更新，但計時依單調時間持續，回來時更新。倒數與碼錶進度只存在本次程式執行中，到時沒有系統通知或鈴聲。

Home.Widgets 保存每個組件的穩定 ID、種類、位置、比例、便箋文字與倒數長度，舊版缺少欄位仍只顯示時鐘。載入去除重複 ID／未知種類並限制數量、文字與分鐘範圍。便箋採明確儲存按鈕，失敗保留編輯內容；移位保存失敗回復原位置。自訂首頁套用與重設外觀不清除組件。

回歸測試涵蓋新增／移除、設定往返、便箋保存、輸入驗證、計時開始／暫停／實際前進、停止畫面更新、窄視窗邊界與自訂首頁保留組件。渲染預覽：artifacts/redesign/widgets/utility-widgets.png。

Release 建置零警告／零錯誤，111 項核心測試、5472 項 UI 斷言通過。已檢查四種組件的渲染預覽及實際視窗中的日曆；電腦操作工具偵測到使用者正在操作後停止輸入，因此本次不宣稱完成工具操控的原生拖曳驗收。

## 組件 UI 統一

實用組件改為整體圓角面板，標題與拖曳提示收進面板；縮放把手改為細小角標，仍僅懸浮／拖曳時顯示。便箋與分鐘欄位使用支援明暗主題、鍵盤焦點與停用狀態的自訂輸入框；所有組件按鈕統一為 36 DIP 高。日曆加大日期間距並標示今天，計時數字使用較清楚的數字字體，輔助提示降低視覺比重。新增選單改為圓角、功能說明與容量提示，保留鍵盤選擇。

不改已有組件的位置、大小或內容。Debug 建置與 111 核心／5477 UI 斷言通過；已檢查 artifacts/redesign/widget-ui 中的明暗主題渲染預覽。

## 統一自繪選單與輸入框

時鐘數字另已改為固定字槽：保留原字體，每個數字置中於相同寬度，冒號位置固定；翻頁時鐘的新舊數字共用同一排版。字槽寬度取實際字體 0–9 的最大寬度，按字體／字級／DPI 快取，不隨時間重新置中整串。114 核心測試、5493 UI 斷言通過，包含秒數 11 → 58 時左半部小時／分鐘像素完全相同的渲染回歸測試。Release 修正版另建置於 artifacts/clock-stable-preview，不覆寫正在執行的版本。

全域 TextBox 採自訂圓角模板，包含熱鍵、時鐘顏色、唯讀背景路徑、便箋及分鐘欄位；文字編輯右鍵選單使用共用選單模板，提供復原、剪下、複製、貼上、全選及快捷鍵提示。命令明確指向原輸入框，保留 WPF 文字編輯、IME、唯讀與命令可用性行為。組件選單、右鍵選單、分隔線與下拉清單的背景、懸浮、選取和停用外觀均由應用自繪。

系統匣保留 NotifyIcon 事件與行為，但選單使用自訂 ToolStripRenderer 完整繪製背景、圓角框、文字、懸浮列及分隔線，配色取自主視窗當前主題；不呼叫預設系統樣式繪製。Windows 視窗標題列、檔案選擇器及確認對話框不屬於本次選單／輸入框替換範圍。

Debug／Release 建置通過，Release 零警告／零錯誤，111 核心測試與 5491 UI 斷言通過。新增輸入框模板、編輯選單命令目標及唯讀剪下／複製檢查；已檢查 custom-controls/custom-editor-menu.png 渲染。系統匣選單的實際多螢幕 DPI 與鍵盤操作仍待人工驗收。
