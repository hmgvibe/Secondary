# 第三階段驗收

範圍：模式策略、分區生命週期、設定保存、手動遊戲快捷鍵。完成後等待使用者確認，未開始第四階段。

## 操作

| 模式 | 可用分區 | 其他入口 |
|---|---|---|
| 全能 | 總覽、工作台、專注、媒體、系統、自動化 | 更多設定 |
| 輕量 | 總覽、專注、媒體、系統 | 更多設定 |
| 遊戲 | 系統 | 退出遊戲（底部及頁面按鈕） |

全域 Ctrl+Alt+G 與系統匣選單可切換遊戲模式。退出恢復進入前模式及該模式最後分區；遊戲中從系統匣選擇顯示器會先退出遊戲並開啟設定。Esc 仍只退出全螢幕，不改變應用模式。沒有自動偵測遊戲、輪詢前景程式或自動模式切換。

「更多」可輸入並套用新快捷鍵，支援 Ctrl／Alt（至少一個）、可選 Shift，加上字母、數字或 F1–F11；排除 Win 與保留的 F12。替換先註冊新鍵，成功才釋放旧鍵。關閉應用會解除註冊；關閉視窗至系統匣則繼續有效。

## 實作邊界

Core ModeController 是模式與導航策略的單一來源，按需建立 ISectionModule，離開分區 Suspend，排除分區 Dispose，返回再建。現在模組是沒有計時器、感測器或背景工作 的 PlaceholderModule；本階段證明生命週期框架，不代表未來真實功能已實作或已通過效能驗證。

設定 v2 保存顯示器、模式、前一非遊戲模式、全能／輕量最後分區、主題、快捷鍵。v1 遷移保留顯示器。無效值回到安全預設；損壞／未知版本於讀取時保留原檔，在後續保存前建立唯一備份。使用同目錄暫存檔原子替換，不在畫面更新時計時寫入。

## 驗收調整：組件自適應寬度

移除內容卡片的星號比例撐滿布局，改用按內容決定寬度、具可讀寬度上限的 WrapPanel。主卡片上限 560 DIP、規劃卡片 360 DIP、設定卡片 480 DIP；窄視窗會縮小並自動換行，卡片高度不強制跟隨同行最高卡片。狀態提示同樣靠左按內容收合，底部導航位置不變。

調整後 42 項核心測試與 2159 項 WPF UI 斷言通過，新增卡片寬度上限、窄視窗邊界與換行不重疊檢查。已查看 1200 DIP 分區、560 DIP 與 1920 DIP 設定頁原生 WPF 渲染；檔案位於 `artifacts/adaptive-width/`，不代表實體副屏驗收。

### 後續：置中與左右留白

組件區最大寬度依使用者後續要求調整為 1600 DIP，整區橫向居中，窄視窗保留左右安全間距。CenteredWrapPanel 保留內容自適應寬度，並逐排置中（包括換行後最後一排）；狀態提示亦居中，底部導航不變。初版 1200 DIP 通過 42 項核心測試、2509 項 WPF UI 斷言，渲染位於 `artifacts/centered-width/`。1600 DIP 更新同步調整寬度上限測試，並新增寬視窗實際達到 1600 DIP 的檢查。
