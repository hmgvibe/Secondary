# 第三階段：快捷導航

快捷導航已由示意頁改為實際本機資料庫，初次使用為空，不自動匯入或執行。所有输入、下拉與右鍵選單沿用自繪模板，編輯與執行確認使用應用自己的對話內容，保留 Windows 視窗框與檔案選擇器。

## 可用功能

- 新增／編輯／複製／刪除捷徑；名稱、分組、文字或符號圖示可自訂。刪除只刪捷徑，不刪原檔。
- 本機程式、遊戲 exe、檔案、資料夾、.lnk、HTTP／HTTPS 網站；exe 支援參數與工作目錄。其他 URL scheme 尚不支援。
- 名稱／分組／目標搜尋、分組篩選、名稱排序、拖曳排序及右鍵往前／往後移動。空分組保存為「未分組」。
- 將桌面／檔案總管的 .lnk、HTTP／HTTPS .url、程式、檔案、資料夾或網址文字拖入快捷導航內容區即可直接新增，不再逐筆開編輯器。每次最多 20 個，原子保存整批結果、自動命名、加入目前分組（全部時為日常），略過重複／失效／不支援項目並顯示結果；新增後清空搜尋讓項目可見。可右鍵再編輯，不會因拖入而執行，仍須首次執行確認。
- 每個捷徑由 1–20 個步驟組成：開啟、等待（1–3600 秒）、指定視窗組合鍵、外部 ps1／bat／cmd。可新增、移除、上下重排步驟；沒有錄製、循環或排程。

## 執行邊界

- 首次執行確認全部目標、參數、目錄和步驟後保存 ApprovedFingerprint，重新啟動仍沿用。不確認或保存失敗不執行。指紋包括捷徑 ID、全部步驟與腳本 SHA256；複製、變更步驟／參數／目標或腳本內容後重新詢問，單純改名／圖示／分組不影響。右鍵「下次執行重新確認」可清除記錄。此記錄是本機便利功能，不是防止其他本機程式竄改資料的安全邊界。一次僅執行一個巨集；取消、任何失敗即停止後續步驟。
- 腳本顯示 SHA256；確認後再次核對並在執行期間持有禁止寫入／刪除的讀取句柄。腳本上限 10 MB，不接受額外參數。bat／cmd 路徑含 shell 特殊字元時拒絕執行。PowerShell 使用系統引擎，不使用 ExecutionPolicy Bypass，不提權。
- 取消會停止自己啟動的直接腳本程序，不終止已開啟的使用者程式，也不殺整個程序樹；腳本自行啟動的子程序可能繼續，已做修改不能撤銷。非零腳本結束碼視為失敗。
- 視窗按鍵限定 Ctrl／Alt（可加 Shift）加字母、數字或 F1–F11。使用者填程序名稱（不含 exe）及完整標題；唯一匹配後請求焦點，重驗程序／視窗／標題／前景與修飾鍵狀態，再傳送按鍵。Windows 拒絕或部分接受時報錯，不繞過權限限制。這不是遊戲注入或按鍵錄製器。
- 進入遊戲、隱藏、最小化、鎖定、暫停或結束應用時取消巨集；普通切頁可繼續。確認視窗開啟期間若被取消，按下確認也不會開始執行。

## 儲存與驗證

獨立 `%LOCALAPPDATA%\Secondary\shortcuts.json`，版本 1、最多 200 筆，原子替換保存，不改既有 settings.json。損壞、不支援或過大的資料檔唯讀保留並報錯，不以空清單覆寫。

核心測試包含儲存往返、搜尋分組、排序、輸入限制、腳本分類、指定視窗要求、巨集順序、單一執行、失敗與取消。UI 測試包含無自動執行的資料載入、搜尋／分組、窄視窗、腳本變更拒絕，以及隔離原生視窗中的編輯與自繪輸入框繼承。渲染測試檔在 artifacts/redesign/stage-3；圖中的捷徑為測試資料，不會加入使用者資料庫。

驗證結果：129 核心測試、5499 一般 UI 斷言通過；含原生編輯對話框的 --live 測試 5543 斷言通過。Release 建置零警告／零錯誤。

編輯器改版：基本資料與編號步驟分區、分組／圖示窄視窗自動換行、排序按鈕邊界停用、進階參數與工作目錄預設收合（已有值時展開），儲存與錯誤提示固定底部。新增首次確認、資料往返、外觀變更沿用、複製／步驟／腳本變更失效測試；核心共 135 項通過。編輯器截圖位於 artifacts/redesign/shortcut-editor。

驗證未執行使用者程式／腳本，也未向真實第三方視窗送鍵。不同程式的參數、檔案關聯、PowerShell 原則、UIPI 焦點限制及真實拖入仍需使用者實機驗收。本階段不啟動監測；第四階段需另外確認才開始。

直接拖入補強：以內容 ScrollViewer 的預覽事件接收外部拖放，包含空白處及搜尋欄，並放行內部捷徑排序事件。.lnk 保存原始路徑、不解析或執行目標，保留連結自身的參數；原連結移動或刪除後會失效。.url 僅讀取 InternetShortcut 節的 HTTP／HTTPS URL，大小上限 64 KiB。自動測試新增批次匯入、重複略過、失效／不安全網址、名稱／原路徑、首次確認未授權、搜尋清除與批次上限，共 135 核心／5505 UI 斷言通過；尚未進行檔案總管跨視窗的實際 OLE 拖放驗收。
