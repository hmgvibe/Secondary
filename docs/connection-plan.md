# 連線模式規格與階段計劃

狀態：計劃已確認（有線連接已討論後移除），C1 已完成並確認，見 [連線模式第一階段](connection-stage-1.md)；C2 已完成並確認，見 [連線模式第二階段](connection-stage-2.md)；C3 已實作，見 [連線模式第三階段](connection-stage-3.md)。每次只實作一個階段，完成後等待使用者確認才繼續。

## 目的

沒有副屏時，用另一臺設備（Windows 或 Linux）執行 Secondary，顯示並操作主電腦的資料。主電腦只執行一個輕量的「連接助手」，只負責採集與傳輸，不顯示介面，以減少主電腦的佔用。

- 主電腦（連接助手）：目前只支援 Windows。
- 連線的設備：Windows（現有 WPF 版）或 Linux（Avalonia 版）。
- 連線的設備仍保有自己的首頁、時鐘、天氣與本機捷徑；連線後，以下功能改為使用主電腦的資料。

## 已確認的方向（使用者 2026-10-18 選定）

- 功能範圍：
  - 遊戲監測：主電腦的 CPU、GPU、記憶體、網路、硬體感測與 PresentMon FPS，在設備的遊戲模式顯示；遊戲程序也在設備上選。
  - 快捷鍵同步進出：在主電腦按 Ctrl+Alt+G（遊戲中也可），連線的設備跟著進入或退出遊戲模式。
  - 主電腦媒體控制：首頁媒體組件可顯示並控制主電腦正在播放的內容。
  - 在主電腦執行捷徑。
- 配對：自動搜尋，加上配對碼。只用區域網路（Wi-Fi 或有線網路）連線。
- 討論後決定暫不支援有線直連：一般 USB 線無法讓兩臺電腦互相通訊，可行的 USB 序列直連線需要另購特定線材。
- 連接助手為系統匣小程式。

## 架構

### 連接助手（主電腦，新專案 Secondary.Connect）

- WinForms 系統匣程式，沒有主視窗。
  - 系統匣選單：連線狀態、開始配對（顯示配對碼）、已配對設備（可移除）、快捷鍵、登入時啟動（預設關閉）、結束。
  - 以一般權限執行，單一實例。
- 沿用 WPF 版已驗證的採集元件，不重寫：
  - 把 WindowsSampler、GpuCounter、PresentMon（含雜湊檢查與工作階段租約）、感測助手用戶端、GameTelemetrySession 搬到新的 Windows 共用庫 Secondary.Windows（net10.0-windows），讓 WPF 版與連接助手共用。
  - 只搬移、不重構；每次搬移後完整執行現有測試，WPF 行為與檢查數量不變。
  - 硬體感測仍由現有的 SensorHelper 子程序提供，PresentMon 仍需要現有的權限條件；連接助手不另外提升權限。
- 平時只有監聽與搜尋回應，加上快捷鍵與系統匣，不採樣。
  - 只有連線的設備正在顯示遊戲頁時才開始採樣；設備離開遊戲頁、隱藏、鎖定或斷線時停止。
  - 採樣率由設備指定（高／低，沿用 SamplingPolicy）。
  - FPS、1% Low 等統計在主電腦用現有的 FrameWindow 算好，每秒只送一份快照（約數 KB），不傳逐幀資料。
- 媒體：沿用 WPF 版的 Windows 媒體工作階段來源，只在設備的媒體組件顯示時訂閱。

### 傳輸與安全

- 只在區域網路使用，不經網際網路，也沒有雲端中繼。
- 搜尋：設備在區域網路廣播 UDP 詢問，連接助手回覆名稱、連接埠與憑證指紋。也可以手動輸入 IP。
- 連線：TCP 上的 TLS 1.3，雙方各有自簽憑證，只接受已配對的指紋。訊息格式為長度前綴的 JSON，帶協定版本；版本不相容時拒絕並說明。
- 配對：
  - 在連接助手選單按「開始配對」後，顯示 6 位數配對碼，2 分鐘內有效。
  - 設備輸入配對碼後，雙方以配對碼驗證彼此的憑證指紋，可防止中間人；錯誤 3 次即作廢這組配對碼。
  - 成功後雙方記住對方，之後自動加密連線，不需要再輸入。
  - 可在任一端移除配對。最多 8 臺已配對設備，同一時間只有 1 臺連線，避免重複採樣。
- Windows 防火牆：第一次監聽時，系統會詢問是否允許，請只允許「私人網路」。若網路設為公用，設定頁會說明為何搜尋不到。
- 心跳與重連：斷線後設備顯示「過期」並以退避方式重連，沿用現有的來源狀態（等待、正常、過期、失敗、停止）。

### 主電腦捷徑

- 權限以主電腦為準：設備只能要求執行，不能直接在主電腦上執行未經確認的內容。
- 設備新增快捷方式時選擇存在本機或主電腦（2026-10-18 改為此方式，不另設分區）；主電腦的捷徑與本機捷徑放在同一組分組並標示「主電腦」。這些捷徑存在主電腦上，並套用 Windows 規則（.exe、.lnk、網址、.ps1／.bat／.cmd、視窗快捷鍵）。
- 首次執行或內容變更後，確認畫面顯示在主電腦螢幕上（目標、參數、腳本 SHA256），必須在主電腦上按確認；設備端只顯示「等待主電腦確認」。
- 確認後記住，沿用現有的雜湊與鎖檔流程。取消、失敗即停止等規則與現有巨集相同。
- 遊戲模式中不執行，與現有規則一致。

### 設備端（WPF 與 Linux）

- 設定新增「連線模式」卡片：列出搜尋到的主電腦、配對、連線或中斷，並顯示狀態與延遲。
- 連線後：
  - 遊戲模式改用主電腦的資料，不在設備本機採樣。程序選擇器列出主電腦的程序。
  - Linux 版的 MangoHud 區塊隱藏，改用主電腦的 PresentMon。
  - 主電腦按快捷鍵時，設備跟著進出遊戲模式；設備本機的快捷鍵仍可使用。
  - 媒體組件可選「本機」或「主電腦」來源。
- 斷線後回到本機資料，並在遊戲頁說明原因。

## 階段

| 階段 | 內容 | 驗收 |
|---|---|---|
| C1 | Secondary.Windows 共用庫抽出、連接助手系統匣程式、搜尋、配對、TLS 連線、心跳與重連；WPF 與 Linux 的「連線模式」設定卡片 | 同一臺 Windows 迴路測試；Windows 主電腦 ↔ Surface 經區域網路；配對碼錯誤、作廢、移除配對、版本不相容 |
| C2 | 遠端遊戲監測（含硬體感測與 PresentMon FPS）、遠端程序選擇、採樣率同步、快捷鍵同步進出 | 主電腦實際遊戲時，在 Windows 與 Linux 設備顯示；斷線與過期顯示「—」；主電腦閒置時的資源佔用 |
| C3 | 主電腦媒體控制、主電腦捷徑（主電腦端確認） | 媒體操作；捷徑首次確認在主電腦、內容變更重新確認、拒絕不執行 |

完成後再進行 Linux L5，連接助手與 Linux 版一起併入下一個 Release。

## 資源目標

- 連接助手閒置（沒有設備連線，或設備不在遊戲頁）：CPU 接近 0%，記憶體約 40 MB 以內。
- 遊戲監測串流（低採樣率）：與現有 WPF 遊戲模式的採集成本相同，不增加介面繪製成本；網路約每秒數 KB。
- 量測方式沿用 scripts/measure.ps1，新增連接助手的情境。

## 不在範圍內

- 主電腦為 Linux 的連接助手。
- 網際網路遠端連線、雲端中繼、手機或網頁用戶端。
- 傳送主電腦畫面或串流遊戲畫面。
- 有線直連（USB 序列直連線等），日後有需要再評估。
