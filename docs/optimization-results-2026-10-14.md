## 2. 幀統計、監測狀態與捕獲生命週期

對應原報告 4.1～4.5、5.1、9.1。

已實作的改善：

- 主交換鏈選擇考慮近期活動，排除已停止的舊鏈，並加入切換遲滯；選定鏈的新鮮度不再由其他鏈的事件代替。
- 幀資料在捕獲鎖內複製快照，統計在鎖外計算；重用陣列、快取未變更的結果，最慢 1% 的計算改用選擇法，減少分組／排序配置。
- CPU、記憶體、網路、GPU、硬體助手及幀來源分別表達等待、正常、失敗、過期或停止狀態，並保存來源最後成功時間。失敗原因不再共用 GPU 狀態欄。
- 無效數值、過期資料及來源停止時顯示不可用狀態，不以零或示意值代替。系統採樣與硬體串流可注入測試來源，以驗證故障與卡住情境。
- PresentMon 輸出讀取、停止及清理加入大小與時間限制。捕獲子程序納入 Job Object；會話使用自身隨機名稱與擁有者身分記錄。

正常停止會嘗試結束自身 ETW 會話；清理失敗保留記錄。**下一次日常正常啟動**會核對原擁有者 PID／啟動時間，對已失聯的自身會話進行有界恢復。量測模式採隔離設定，並不執行這項日常啟動恢復。

Job Object 的子程序生命週期保護，不能直接證明父程序被強制終止後 ETW 會話會立即清理。真正成功捕獲時的強制終止、會話殘留及下一次正常啟動恢復，仍須在有 ETW 權限的環境驗證；不應以模擬會話或一般子程序測試替代。

仍需後續完成：

- 有權限環境中的 DX11／DX12、視窗／全螢幕切換、程序退出、交換鏈重建，以及與官方 PresentMon 同區間輸出的數值對照。
- 多廠商 GPU／CPU 感測器能力映射、GPU 選擇偏好保存、優先呈現確切 package power 的策略。
- 網卡選擇及實體／虛擬／VPN 並存時的重複統計驗證。現行網路資料仍是整機流量。

天氣已加入多個城市候選及城市／行政區／國家顯示，使用者確認後才保存選定座標。舊設定中的城市字串保留，待確認地點，不自動把首筆搜尋結果寫回。

**天氣讀數快取只存在程序內**；選定地點／座標會保存，離線讀數不會跨重啟恢復。城市設定說明查詢會傳送至 Open-Meteo，資料旁提供來源與授權連結。

媒體組件共用 Windows 管理器、快照與工作階段事件，隱藏時解除訂閱。播放控制依播放器能力啟用，支援獨立 Play／Pause 能力，等待與封面讀取有取消及期限。取消中的封面不提前標成已載入；同首歌曲之後才提供的封面可在媒體屬性事件後更新。

天氣的候選確認、保存失敗、逾時、共享取消、快速返回、亂序回應與過期值，使用可替換 HTTP／時間來源進行回歸。這些測試驗證應用程式的流程，不保證外部服務永遠可用。真實播放器的按鈕能力、封面變更、播放時間與控制回饋仍未完成驗收。
