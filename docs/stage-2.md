# 第二階段：設計系統與固定導航

本階段經使用者「繼續」授權，範圍為介面殼層及外觀預覽。第三階段尚未開始。

## 已實作

- 固定底部置中的橫向膠囊導航：總覽、工作台、專注、媒體、系統、自動化、更多。依使用者提供的參考圖改為圓形圖示按鈕、白色選取狀態及設定前的分隔線，位置維持底部。
- 六個獨立的分區空狀態：各自有標題、說明與功能預留項目，不偽造監控或媒體數據。
- 右上角全能、輕量、遊戲外觀即時切換；全部分區仍可預覽，不包含模式限制或服務生命週期。
- 更多頁整合顯示器選擇、全螢幕、返回視窗與明暗主題。
- 預設跟隨 Windows 明暗變化；可在當次執行切換淺色或深色；遊戲固定深色。
- 共用動態資源：表面、文字、分隔線、選取、焦點、圓角及控制項樣式。
- Segoe UI Variable、繁體中文後備字型及 Segoe Fluent Icons；無外部字型或圖示下載。
- 窄於 900 DIP 時內容轉為單欄，內容獨立捲動，底部導航保持原位。
- 主要控制項至少 44 DIP 高；導航以圖示呈現，保留工具提示、無障礙名稱、選取指示及圓形鍵盤焦點框。全能外觀有静態選取光暈，輕量外觀減弱光暈，遊戲外觀完全移除導航陰影與光暈。
- 高對比採 Windows 系統色並取消裝飾；動畫遵守 Windows「動畫效果」設定。

| 外觀 | 表面 | 面板圓角 | 切頁 |
|---|---|---|---|
| 全能 | 單一視窗 DWM Mica 加半透明表面；失敗降級實色 | 18 DIP | 160ms 淡入與輕位移 |
| 輕量 | 不透明柔和實色，沒有模糊 | 24 DIP | 120ms 淡入與輕位移 |
| 遊戲 | 近黑底、清晰分隔、無漸層或特效 | 4 DIP | 無動畫 |

Mica 依照 Microsoft 的 [DWM 視窗屬性](https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/ne-dwmapi-dwmwindowattribute) 與 [WPF 框架延伸方式](https://learn.microsoft.com/en-us/dotnet/desktop/wpf/graphics-multimedia/extend-glass-frame-into-a-wpf-application) 實作。系統是否呈現材質仍取決於 Windows 版本與合成設定；每個面板不獨立模糊。

## 驗證

- Debug 與 Release 建置，零警告、零錯誤。
- 12 項第一階段核心測試通過。
- 膠囊導航更新後 UI 測試通過 2,157 個檢查點：六區導航、唯一選取、更多頁、顯示器友善名稱、高對比、圓形按鈕、工具提示及主題降級等。
- 膠囊外框圓角依實際高度的一半計算，取代固定 52 DIP；80 組版面皆驗證兩端為半圓，避免 WPF 對過大圓角做不同比例的軸向縮放。
- 導航名稱改為自訂 ToolTip 模板：深色圓角、14 DIP 字級、底部小箭頭；固定置中於按鈕上方，延遲 250ms 顯示，遊戲外觀取消陰影。已檢查實際懸浮畫面，存於 `artifacts/stage-2-capsule/tooltip-*.png`。
- 80 組版面組合：1920×1080、2560×1440、3840×2160、1080×1920，各搭配 100%、125%、150%、200% 等效縮放及五組有效明暗／外觀組合。
- 檢查底部位置、內容不覆蓋導航、膠囊寬度不溢出、44 DIP 操作區域、圓形比例、無障礙名稱與文字對比至少 4.5:1。
- 原生 WPF 渲染檢查與實際 Windows 操作皆已執行；實際檢查涵蓋外觀選擇、更多頁、主題下拉選單及全螢幕／Esc 返回。
- 驗證期間修正兩個問題：淺色選取背景的輔助文字對比不足、顯示器 ComboBox 顯示完整 record 字串。新增回歸檢查。

## 驗收方式與限制

啟動程式後依次切換六個底部分區，再比較右上角三種外觀；於「更多」比較深淺主題，縮小視窗確認內容可捲動且導航仍可操作。確認配色、字級、圓角、密度及導航尺寸後，再進入第三階段。

目前六區都是預留頁面。遊戲外觀不是已優化的遊戲模式，本階段不承諾其 CPU 或記憶體達到第四階段預算。80 組版面檢查以 WPF 邏輯尺寸模擬縮放，不等同在每台實體螢幕上改變 DPI 或拔線。真正的觸控裝置、螢幕閱讀器及 Windows 高對比切換仍需使用者實機確認。
