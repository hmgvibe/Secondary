# 連線模式第四階段：主電腦的 AI 用量

狀態：已實作，所有自動測試通過。Windows 主電腦與 Surface 之間的實機驗證尚未進行，等待使用者確認。

## 交付內容

- **AI 用量組件的來源切換**
  - 組件底部那一列，左邊是「每分鐘自動更新」，右邊新增「本機／主電腦」按鈕。來源存在組件設定裡（HomeWidgetSettings.UsageSource），沒有增加組件高度。
  - 這台設備已經和主電腦配對過時，新加入的 AI 用量組件預設「主電腦」（使用者 2026-10-20 確認）；其他情況預設「本機」。
  - 選「主電腦」後，組件顯示主電腦上 Claude 和 Codex 的用量，兩個區塊的更新時間前面加「主電腦 ·」。
  - 狀態提示：

    | 狀況 | 顯示 |
    |---|---|
    | 這台設備沒開連線模式 | 「連線模式未啟用；可切回本機」 |
    | 已設定但目前斷線 | 「主電腦未連線；連上後自動顯示」，不會留下舊數字 |
    | 剛訂閱、還沒收到回報 | 「等待主電腦回報用量」 |
    | 主電腦是 C4 以前的連接助手 | 等 10 秒沒有回報後，顯示「主電腦的連接助手版本較舊，請更新後再試」 |

- **訂閱與更新**
  - 只有在設為「主電腦」、自動更新沒有暫停、而且組件正在畫面上時，設備才會送出 `usage-watch`。組件隱藏、移除、暫停、切回本機或斷線時就取消訂閱。
  - 多個組件共用一個訂閱。送出的請求是所有組件的聯集：要讀哪些服務（Claude、Codex），以及是否要線上用量。最後一個組件離開時，送出停止。
  - 斷線後重新連上，如果還有組件在看，請求會自動重送。
  - 設備端的計時器每分鐘只重算倒數，不讀本機檔案。倒數用主電腦的時鐘計算：設備從每則回報的 `sent` 推算兩台電腦的時間差。

- **連接助手（主電腦）**
  - 新增 UsageService，寫法比照 MediaService。被訂閱時立刻讀一次，之後每 60 秒讀一次，內容沒變就不送。沒有訂閱時完全不讀檔。
  - 讀取沿用共用的 AiUsageService，只讀設備要求的服務，因此組件「只顯示 Codex」時，主電腦也不會讀 Claude 的紀錄。
  - 系統匣多一行「AI 用量：設備正在顯示主電腦的用量／未使用」。
  - 系統匣新增「允許設備使用 Claude 線上用量」，預設關閉（使用者 2026-10-20 確認）。勾選前會先說明 token 只在主電腦使用、不會傳給設備。設定存在 `%LOCALAPPDATA%\Secondary\Connect\usage.json`。
  - 沒有允許時，即使設備要求線上用量，主電腦也不會呼叫端點，設備會顯示「線上用量無法取得：主電腦未允許線上用量（在連接助手選單開啟）」。

- **協定**
  - 協定版本仍是 1，不需要重新配對。
  - 新增兩種訊息：
    - `usage-watch`（設備 → 主電腦）：`on`、`claude`、`codex`、`claude-online`。
    - `usage-state`（主電腦 → 設備）：`sent`（毫秒）、`status`，`claude`／`codex` 各含 `five-hour`、`weekly`（`used`、`resets`、`reached`）與 `observed`，以及 `claude-online-problem`。
  - 設備會逐欄檢查 `usage-state`：百分比必須在 0–100，時間必須在合理範圍，文字最多 300 字，布林值型別要正確。有任何一欄不合格就整則丟掉。
  - 舊版連接助手會忽略未知的訊息類型，所以新設備連舊主電腦不會出錯，只會顯示版本提示。

- **線上用量的確認文字**：組件來源是「主電腦」時，組件右鍵選單的「Claude 線上用量（非官方）」改用另一段確認文字，說明 token 留在主電腦，主電腦也需要允許。

- **測試**
  - 核心測試 439 項，新增 29 項：
    - 訊息往返，以及 9 種不合格內容會被拒絕。
    - 透過回送連線接假的主電腦，驗證：沒有組件時不讀、只要求顯示的服務、多個組件合併成一個請求、最後一個離開時停止、斷線清除資料、重連後重送、主電腦時鐘換算、舊版連接助手的提示。
  - WPF UI 測試 6,836 項斷言，新增 18 項。使用真的系統匣和 UsageService，搭配假的讀取來源，驗證：
    - 來源切換會儲存，系統匣狀態行會變。
    - 主電腦未允許時說明原因，也不會呼叫線上用量。
    - 在系統匣取消確認時保持關閉；允許後會存檔、立刻改讀線上用量。
    - 只顯示 Codex 會縮小讀取範圍；暫停、切回本機會停止主電腦讀取。
    - 已配對時，新組件預設「主電腦」。
  - Linux 外殼檢查 375 項，新增 12 項，內容與 WPF 相同，使用假的連接助手。
  - 本機 UI 檢查照例暫時放寬 150% DPI 下已知的 44 DIP 導航檢查，跑完已還原。

## 尚未驗證

- 連接助手被訂閱期間的資源佔用。
