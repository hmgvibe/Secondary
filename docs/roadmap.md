# Secondary 新版階段進度

舊版路線圖已撤銷，以下為使用者確認的新計劃。每次只實作一個階段，完成後等待使用者確認才繼續。

| 階段 | 內容 | 狀態 |
|---|---|---|
| 1 | 新外殼、兩頁一模式、v3 遷移、三畫面預覽、遊戲進場動畫 | 已確認，使用者指示進入下一階段 |
| 2 | 三款時鐘、本機圖片／影片／內建動態背景、首頁組件、設定與資源釋放 | 已確認，使用者指示進入下一階段；見 redesign-stage-2.md |
| 3 | 快捷導航、分組搜尋排序、步驟式巨集與外部腳本 | 已確認，使用者指示進入下一階段；見 redesign-stage-3.md |
| 4 | PresentMon 與可選硬體感測元件、權限與實機資料驗證 | 使用者指示進入第五階段；GPU 已驗證，ETW／CPU 底層權限限制保留；見 redesign-stage-4.md |
| 5 | 真實遊戲儀表、曲線、程序選擇及高／低採樣 | 已接入，等待驗收；FPS 成功實機採集仍受 ETW 權限阻礙；見 redesign-stage-5.md |
| 6 | 無障礙、實體副屏、長時間效能、打包發布 | 已有本機打包與回歸流程；2026-10 優化加入候選包驗證、輕量包、鍵盤操作及效能場景；實體副屏、長時間及成功 FPS 實機驗收仍待完成 |

技術沿用 Windows 11 x64、C#、WPF、.NET 10。日常只有首頁與快捷導航，遊戲為獨立手動模式，不再有全能／輕量模式。日常底部導航固定為「首頁｜快捷導航｜遊戲模式｜設定」。遊戲中底部提供監測、退出、設定；設定為獨立頁面，不改變分區或返回位置。

新計劃見 [新版規格](redesign-plan.md)，第一階段狀態見 [新版第一階段](redesign-stage-1.md)。原 stage-1 至 stage-4 文件及 artifacts/stage-4 是舊版歷史紀錄，不代表新版功能、效能或驗收狀態。
