# 新版產品規格

## 已確認的方向

- 基於現有 WPF 外殼改造，不另起專案；移除舊六分區與全能／輕量模式。
- 日常兩頁：首頁、快捷導航。底部固定「首頁｜快捷導航｜遊戲模式｜設定」，取消頂部模式切換。
- 遊戲模式手動進出、手動選擇遊戲程序；退出返回前頁。設定使用獨立頁面，從底部導航進入。
- 保留副屏選擇、DPI、全螢幕／原生視窗、系統匣、快捷鍵、內容置中與 1600 DIP 上限。首頁背景可鋪滿。

## 首頁

依後續確認改為自由拖曳／縮放組件畫布：時鐘、日曆、便箋、倒數與碼錶。時鐘數字／翻頁／指針三款，數字固定字槽；可調大小、顏色、相對位置、12／24 小時、日期與秒數。圖片、MP4 H.264 循環靜音影片；預設靜態。原有的緩慢漸層與柔和流光兩款內建動效已依使用者要求移除，舊設定載入時改為靜態背景。WPF MediaElement 媒體失敗回退靜態，不裝編解碼器。離頁、隱藏、最小化、鎖定或進入遊戲停止並釋放背景資源。導航欄支援標準／80% 尺寸與四邊位置；首頁外觀由獨立彈窗管理。

## 快捷導航

整齊圖示格；程式／遊戲／檔案／資料夾／網站／.lnk，名稱圖示分組可調，搜尋、拖入新增、拖曳排序。程式可填參數與工作目錄。

步驟式巨集包括開啟、等待、指定視窗快捷鍵、外部 .ps1／.bat／.cmd 腳本。不做錄製、程式碼編輯器、循環或排程。新增不執行，首次／變更後確認，單一巨集、可取消、失敗即停；傳送按鍵前驗證目標焦點，不繞過 Windows 限制。一般權限執行，不繞過 PowerShell 原則，不借用監測輔助程序提權。取消只終止自己啟動的腳本，不關閉已開啟的使用者程式；進入遊戲取消巨集。

## 遊戲儀表

深色精密儀表＋青藍重點色。頂部選程序／資料來源狀態／採樣設定；FPS、1% Low、幀時間主要讀數。左 CPU→GPU→記憶體固定垂直分組，右幀時間及歷史曲線，下方網路等輔助資訊；窄視窗依閱讀順序單欄，不用旧瀑布流。

完整目標為 FPS、1% Low、幀時間、CPU／GPU 使用率／溫度／頻率／功耗、顯存、記憶體、網路。資料不可用明確說原因，不填假值。PresentMon 獨立 console 指定 PID 讀標準輸出；LibreHardwareMonitor 置於可選監測輔助程序。先驗證支援度、授權與發行版本；需要權限時使用者可拒絕。不注入遊戲、不做遊戲內 overlay、不關閉安全功能、不停止他人的 ETW 工作階段。

主介面保持一般權限，輔助程序只提供監測、限制目前使用者通訊，不提供任意命令執行。統一樣本包含時間、來源、裝置／程序識別及可用狀態。幀統計採同一程序最活躍交換鏈；1% Low 是最近 60 秒最慢 1% 有效幀時間平均值換算，樣本不足顯示等待。歷史環形緩衝有界；換程序清空相關統計；程序退出不自動換目標。

低採樣基本 3 秒、GPU 10 秒、UI 最多 1 Hz；高採樣基本 1 秒、GPU 2 秒、UI 最多 2 Hz。幀事件持續採集再聚合，不能用 UI 刷新率冒充 FPS。離模式、隱藏或最小化停止採樣與輔助程序。

進場約 1.2 秒：淡出、掃描線、儀表展開；結束移除動畫層，不持續裝飾重繪，可關閉、遵循減少動畫、高對比，中途進出立即取消。正常退出短淡出；退出操作不得被轉場阻擋。

## 交付原則

每階段等待使用者確認；階段依 roadmap.md。第一階段只做設計預覽，所有監測和捷徑示意需明確標示且不接真實來源。舊監測代碼可保留供重用，但不得在預覽中啟動。

v3 設定遷移保留舊檔備份，明確映射數字模式；舊日常頁回首頁，副屏／主題／快捷鍵／採樣偏好保留。後續首頁、捷徑與巨集模型隨所屬階段加入，避免預先鎖死未驗收介面。

功能完整但嚴控常駐開銷；分別量測主程序、輔助程序與合計，不沿用舊 100 MiB 承諾。影片／靜態首頁、低／高採樣、快速切換及長時間資源趨勢都要驗證。第一版不做雲端同步、線上桌布商店、Wallpaper Engine 整合、自動進出遊戲。
