# Secondary v1.2.0

本版新增快捷導航的匯出／匯入，並讓捷徑可以在本機與主電腦之間移動。

## 快捷導航

- 新增「匯出設定」與「匯入設定」：把捷徑、分組與排列方式存成一個檔案，可在另一臺設備或重裝後匯入。匯入會取代目前的設定，取代前會自動備份。
- Windows 與 Linux 之間互相匯入時，這臺設備無法執行的捷徑會顯示為「待處理」：可以移到主電腦執行、編輯成這臺設備可用的內容，或刪除。待處理的捷徑不會在這臺設備上執行。
- 連線到主電腦時，編輯任何捷徑都可以選擇存放在「本機」或「主電腦」，捷徑會移過去。
- 匯入或移動過的捷徑，第一次執行時都需要重新確認。

## Linux 版

- 檢查捷徑時會依系統判斷路徑：Windows 的 `C:\…` 路徑在 Linux 上不再被當成可用。之前存下的這類捷徑會自動改列為「待處理」。
- 從 AppImage 改用 .deb 安裝後，如果之前加入的應用程式選單項目蓋過了安裝包的項目，設定頁會提示，按「從選單移除」即可改用安裝包的項目。

## 下載與更新

各發行包都已包含所需的 .NET 執行環境。使用同一 Release 的 `SHA256SUMS.txt` 核對下載檔案。

- Windows 11 x64：`Secondary-v1.2.0-windows-x64.zip`。先從系統匣完全退出目前程式，解壓後啟動新目錄的 `Secondary.App.exe`，既有設定與布局會沿用。
- Linux x86_64：`secondary_1.2.0_amd64.deb`（`sudo apt install ./secondary_1.2.0_amd64.deb`）或 `Secondary-v1.2.0-linux-x86_64.AppImage`；`Secondary-v1.2.0-linux-x86_64.tar.gz` 是相同檔案的壓縮包。
- 連接助手（主電腦，Windows 11 x64）：`Secondary-Connect-v1.2.0-windows-x64.zip`。解壓後執行 `Secondary.Connect.exe`。只在使用連線模式時需要。

## 注意事項

- 連線模式只在同一個區域網路內使用，主電腦需為 Windows 11 x64 並執行連接助手。
- Windows 版不會自動提權或安裝驅動。CPU 溫度、功率與頻率需要支援的硬體、PawnIO 及裝置存取權限；FPS 採集需要足夠的 ETW 權限。
