# Secondary v1.3.0

本版新增「AI 用量」組件，可在首頁查看 Claude（Claude Code）與 Codex 的五小時和每週額度。

## AI 用量組件

- 從首頁「＋ 組件」加入。顯示各服務五小時與每週的已用百分比、進度條、重置倒數和資料更新時間。
- 預設只讀這台電腦上的紀錄，不連網路，也不讀登入憑證：
  - Codex：讀取 Codex 的本機紀錄，使用 Codex 後就會出現。
  - Claude：Claude 桌面版不提供用量百分比，額度用完時會顯示重置時間。使用 Claude Code CLI 時，可以另外設定 statusLine 取得百分比，做法見說明文件。
- 標題右鍵選單：
  - 可選「顯示 Claude 和 Codex」、「只顯示 Claude」或「只顯示 Codex」。不顯示的服務完全不讀取。
  - 「Claude 線上用量（非官方）」預設關閉。開啟後會讀取 Claude Code CLI 的登入資訊，向未公開的用量端點取得百分比，最多每 5 分鐘一次。只用 Claude 桌面版登入時無法使用。
- 組件底部的「每分鐘自動更新」取消勾選後會暫停讀取，保留最後一次的數字；重新勾選會立刻更新。
- Windows 與 Linux 版都有。

## 連線模式

- AI 用量組件可以切換成「主電腦」，顯示主電腦上的用量。設備已和主電腦配對時，新加入的組件預設「主電腦」。
- 主電腦只在組件顯示、而且沒有暫停時才讀取，組件離開後就停止。
- 線上用量在主電腦上取得，登入資訊不會傳到設備。需要先在主電腦的連接助手系統匣選單勾選「允許設備使用 Claude 線上用量」（預設關閉）。
- 要使用這個功能，主電腦的連接助手也需要更新到 v1.3.0。舊版連接助手會顯示「版本較舊」的提示，其他連線功能不受影響。

## 下載與更新

各發行包都已包含所需的 .NET 執行環境。使用同一 Release 的 `SHA256SUMS.txt` 核對下載檔案。

- Windows 11 x64：`Secondary-v1.3.0-windows-x64.zip`。先從系統匣完全退出目前程式，解壓後啟動新目錄的 `Secondary.App.exe`，既有設定與布局會沿用。
- Linux x86_64：`secondary_1.3.0_amd64.deb`（`sudo apt install ./secondary_1.3.0_amd64.deb`）或 `Secondary-v1.3.0-linux-x86_64.AppImage`；`Secondary-v1.3.0-linux-x86_64.tar.gz` 是相同檔案的壓縮包。
- 連接助手（主電腦，Windows 11 x64）：`Secondary-Connect-v1.3.0-windows-x64.zip`。解壓後執行 `Secondary.Connect.exe`。只在使用連線模式時需要。

## 注意事項

- AI 用量讀取的是 Codex 與 Claude Code 的內部紀錄格式，這些格式沒有公開文件，工具改版後可能暫時讀不到；讀不到時組件會顯示「沒有資料」，不影響其他功能。
- 「Claude 線上用量」使用未公開的端點，隨時可能失效或改變格式。
