# Secondary v1.0.2

本版改善首頁布局操作、時鐘效果、組件內容縮放，以及資料保存、監測與背景資源的穩定性。

## 首頁與時鐘

- 所有組件支援四角、四邊拖曳縮放，對側保持固定，寬高可獨立調整。
- 拖動或縮放時，接近畫布與其他組件的邊線、中心線會吸附並顯示虛線；Alt 暫時略過吸附，Esc 取消並回復，放開後保存。
- 日曆、便箋、待辦、倒數與媒體等內容隨可用大小調整，保留編輯草稿與選取範圍。
- 時鐘外框依內容量測；翻頁動畫只更新變動數字，改善上下半頁的銜接。
- 新增組件會尋找空白位置，並可從功能表選取被遮住的組件。

## 穩定性與效能

- 保存失敗可重試，同一設定檔只保留一個寫入者；資料讀取加入大小限制。
- 改善 PresentMon 來源選擇、幀統計與監測停止時的程序清理，分別追蹤來源有效期。
- 圖片改為背景解碼，天氣與媒體共用資料來源；離頁時釋放背景資源。
- 小視窗提供緊湊遊戲摘要；導航操作範圍保留至少 44 DIP。
- 加入 Windows 持續整合、鎖定依賴、安全檢查與打包啟動驗證。

## 下載與更新

Windows 11 x64：下載 `Secondary-v1.0.2-windows-x64.zip`。包含所需 .NET 執行環境，先從系統匣完全退出目前程式，解壓後啟動新目錄的 `Secondary.App.exe`，既有設定與布局會沿用。使用同一 Release 的 `SHA256SUMS.txt` 核對下載檔案。

## 驗證與已知限制

Release 建置及依賴安全檢查通過；核心測試 233 項、介面與整合檢查 6,790 項，涵蓋 80 種視窗／縮放／主題組合及原生 WPF 視窗回歸。八方向拖曳與吸附以程式化事件、幾何及命中區測試覆蓋；實體滑鼠手感、混合 DPI、拔插與長時間副屏驗收仍待完成。

本版沒有解除 CPU 底層感測或 PresentMon 的系統權限限制。CPU 溫度、功率與頻率需要支援的硬體、PawnIO 及裝置存取權限；FPS 採集需要足夠的 ETW 權限。程式不會自動提權或安裝驅動，成功遊戲幀資料的實機採集仍待有權限環境驗證。
