# Secondary v1.1.0

本版新增 Linux 版與連線模式：沒有副屏時，可用另一臺 Windows 或 Linux 設備顯示並操作主電腦。

## Linux 版（Ubuntu／GNOME）

- 以 Avalonia 製作，與 Windows 版共用核心邏輯：外殼與設定、首頁組件與時鐘、快捷導航（.desktop 啟動器、步驟式巨集與 .sh 腳本）、遊戲模式。
- 遊戲模式的 FPS 讀取 MangoHud 記錄檔，需自行安裝 MangoHud，並在遊戲啟動選項加入 Secondary 提供的設定。
- 提供 .deb 安裝包與免安裝的 AppImage。.deb 安裝到 `/opt/secondary`，並加入 `secondary` 指令與應用程式選單；安裝後 GNOME 就允許綁定全域快捷鍵。

## 連線模式

- 主電腦執行新的「連接助手」（系統匣程式）。設備在設定頁的「連線模式」搜尋主電腦，以連接助手顯示的 6 位數配對碼配對；只在區域網路內連線，並以 TLS 1.3 加密。
- 遊戲監測：設備可選擇主電腦上的遊戲程序，顯示主電腦的 FPS 與感測資料；快捷鍵在兩端同步進出遊戲模式。
- 媒體：首頁媒體組件可切換為控制主電腦正在播放的媒體。
- 快捷導航：新增捷徑時可選擇存放在本機或主電腦。主電腦捷徑和本機捷徑放在同一組分組中，標示「主電腦」，由主電腦執行；第一次執行（或步驟變更後）要在主電腦畫面上確認，遊戲模式中不會執行。

## 其他變更

- 快捷導航頁移除搜尋框，改以分組選單篩選。
- 監測、桌面與連線相關程式抽出為 Windows 共用庫，供主程式與連接助手共用。

## 下載與更新

各發行包都已包含所需的 .NET 執行環境。使用同一 Release 的 `SHA256SUMS.txt` 核對下載檔案。

- Windows 11 x64：`Secondary-v1.1.0-windows-x64.zip`。先從系統匣完全退出目前程式，解壓後啟動新目錄的 `Secondary.App.exe`，既有設定與布局會沿用。
- Linux x86_64：`secondary_1.1.0_amd64.deb`（`sudo apt install ./secondary_1.1.0_amd64.deb`）或 `Secondary-v1.1.0-linux-x86_64.AppImage`；`Secondary-v1.1.0-linux-x86_64.tar.gz` 是相同檔案的壓縮包。
- 連接助手（主電腦，Windows 11 x64）：`Secondary-Connect-v1.1.0-windows-x64.zip`。解壓後執行 `Secondary.Connect.exe`，可在系統匣選單設定登入時啟動。只在使用連線模式時需要。

## 驗證與已知限制

- Windows：核心測試 341 項，介面與整合檢查 6,778 項（涵蓋 80 種視窗／縮放／主題組合）通過；Windows 上的 Linux 外殼檢查 325 項通過。
- Linux（Ubuntu 26.04，Surface Pro 7）：核心測試 342 項、Linux 外殼檢查 359 項通過。
- 三種發行包都在打包後實際啟動一次並通過檢查；.deb 以 `apt-get -s` 模擬安裝，依賴全部可滿足。
- 連線模式的遊戲監測與快捷鍵同步已在實機遊戲中驗證。主電腦媒體控制與主電腦捷徑只經過自動測試，尚待實機驗證。
- Linux 版的長時間資源、讀屏與鍵盤操作、實體副屏驗收仍待完成；真正的 MangoHud 記錄尚未在實機上測試。Linux 發行包尚未附上第三方套件的授權聲明。
- 沿用 v1.0.2 的限制：Windows 版不會自動提權或安裝驅動。CPU 溫度、功率與頻率需要支援的硬體、PawnIO 及裝置存取權限；PresentMon 的 FPS 採集需要足夠的 ETW 權限。
