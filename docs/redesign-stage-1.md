# 新版第一階段：新結構與視覺預覽

狀態：實作與測試完成，等待使用者外觀確認；未進入第二階段。

## 交付內容

- 日常 home／shortcuts 與獨立 game；AppMode 僅 Normal=0、Game=2。頂部模式選擇已移除，底部提供四個入口，遊戲中可退出。
- 設定改為獨立頁面，與其他頁面共用內容區及捲動，不使用遮罩或浮動面板。進入時隱藏先前內容；底部導航、返回按鈕及 Esc 可離開，保留日常返回位置。
- 靜態時鐘、六張示意快捷圖示、FPS／硬體／曲線儀表預覽。示意皆明確標示，不啟動捷徑、腳本、程序列舉或監測。
- 約 1.2 秒掃描／淡出／儀表滑入，完成及取消時 Remove storyboard、移除覆蓋層；隱藏、最小化、設定與減少動畫情境取消。不再強制遊戲 SoftwareOnly，尚未宣稱新版效能改善。
- v1／v2 遷移 v3，備份原檔並保留副屏、主題、快捷鍵與採樣偏好。Light 不再存在；舊 Game=2 保持遊戲模式；日常舊頁回首頁。
- 舊監測元件及舊測試資料保留，不從新版 composition root 建立。舊 --measure 和 measure.ps1 停用。

## 驗證方法

核心測試包含 v1／v2 × 三種原數字模式、逐字備份、保存冪等、壞檔、安全模式恢復及生命週期。UI 測試涵蓋 80 視窗／縮放／主題組合、導航與 tooltip、設定面板、內容上限、硬體垂直排列、回前頁、示意標示、無真實採樣、高對比和舊採樣器假資料回歸。

artifacts/redesign/stage-1 的 PNG 為明確標示 DESIGN-PREVIEW 的離屏 WPF 渲染，不是實際遊戲數據或實體副屏證據。實體拔線、影片播放、FPS 資料來源與效能測試屬後續階段。

## 本輪結果

- Debug／Release 編譯零警告、零錯誤；90 項核心測試及 1870 項 UI 斷言通過。
- 額外以 --live 啟用獨立設定的真實 WPF 視窗測試，1891 項斷言通過：包含動畫自然完成、8 輪中途進出、設定打斷、隱藏清理；不註冊全域快捷鍵、不改變顯示器配置。
- 使用 computer-use 檢查正式預覽的底部遊戲入口，實際看到 GAME MODE 轉場及其後的儀表，並驗證遊戲內設定為覆蓋面板。
- 首頁目前仍是靜態樣式，不是真實走動時鐘；未實作影片、快捷執行或真實性能監測，也未重測資源佔用。

## 設定獨立頁面調整

依使用者後續要求取消原覆蓋面板，改為 SettingsPage，卡片按可用寬度排列、單卡上限 480 DIP，外層上限 1600 DIP。遊戲模式也可進入設定，遊戲退出入口不變；查看設定時不啟動遊戲進場動畫。設定頁不取代保存的日常頁，重新啟動仍恢復既有模式及日常位置。

90 項核心測試與 2950 項 UI 斷言通過，包含前頁隱藏、無模態遮罩、設定卡片邊界與返回行為。新畫面位於 artifacts/redesign/settings-page；前述原生覆蓋面板檢查是變更前歷史紀錄。

### 設定單欄加寬

依後續要求，設定卡片固定單一直欄，由上往下接續，不再依寬度拆為多欄。單卡最大寬度增加至 800 DIP，整欄置中，窄視窗自動縮小，卡片間距 16 DIP。90 項核心測試與 4198 項 UI 斷言通過；新畫面在 artifacts/redesign/settings-single-column。仍為第一階段外觀調整。

### 遊戲科幻 HUD 與局部儀錶

遊戲頁移除所有 Panel 卡片底框，改用開放式排版、靜態座標網格、角標、細線分隔。FPS 為大型環形讀數，CPU／GPU 使用 270 度分段刻度儀錶；記憶體與顯存為線性用量條，幀時間保留軌跡圖。底部導航與既有進場動畫不变。所有數值與曲線仍為明確標示的設計示意。

HudGrid、HudGauge 為原生向量繪製，無持續計時器；裝飾只隨尺寸或樣式變更重繪。90 項核心測試及 4278 項 UI 斷言通過，含無卡片底框、兩個硬體刻度錶、窄畫面排列與既有設定頁回歸。畫面位於 artifacts/redesign/game-hud。
